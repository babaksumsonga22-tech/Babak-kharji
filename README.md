# خرج‌نگار (KharjNegar)

اپلیکیشن فارسی ثبت مخارج روزانه برای Android 13 و بالاتر/پایین‌تر (حداقل نسخه به تنظیمات Flutter بستگی دارد).

## امکانات نسخه اولیه
- ثبت مخارج به تومان با ورودی فقط عددی
- ذخیره محلی با SQLite و بدون نیاز به حساب یا سرور
- دسته‌بندی‌های قابل مدیریت
- سابقه، ویرایش و حذف هزینه
- نمودار هفت روز اخیر و گزارش دسته‌بندی
- تاریخ شمسی در نمایش
- قفل اختیاری برنامه با رمز
- پشتیبان‌گیری رمزگذاری‌شده AES-256-GCM و بازیابی

## ساخت APK
نیازمند Flutter SDK و Android SDK:
```bash
flutter pub get
flutter build apk --release
```
فایل خروجی:
`build/app/outputs/flutter-apk/app-release.apk`

## نکته مهم
این بسته سورس پروژه است، نه فایل APK کامپایل‌شده. برای تولید APK باید Flutter و Android SDK روی یک رایانه یا سرویس build نصب باشد.
پیش از استفاده واقعی، پروژه را روی دستگاه آزمایش و نسخه پشتیبان را با چند رمز و فایل آزمایشی بررسی کنید.
